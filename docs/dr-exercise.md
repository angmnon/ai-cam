# DR 演练记录（H-5）

> 目标：验证 RPO ≤ 15min / RTO ≤ 2h 的恢复能力。每季度执行一次，本文件为模板 + 历次记录。

## 演练清单

1. 停止主实例（模拟故障）
2. 从对象存储拉取最近全量备份 + WAL 归档（确认 < 15min 前状态）
3. 恢复 DB：`pg_restore` 或归档回放
4. 启动应用镜像（旧版本 tag）
5. 健康检查 + Golden 冒烟（零件解析 + 一个 CAM 任务）
6. 记录耗时、缺口、改进项
